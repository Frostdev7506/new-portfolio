# Illustration assets

Generated with the built-in imagegen tool from the user-approved notebook mockups. Shared prompt direction: fine dark pen contours, warm cream paper, restrained watercolor/pencil shading, teal cables, orange accents, no surrounding website UI. Transparency requested for every decorative asset; the four project covers use an opaque cream background. Original generated PNGs are preserved; Next.js serves responsive image variants.

- `public/illustrations/brand.png`: Orange N and teal B keycaps, looping teal cable, cream browser with code symbol; sidebar identity.
- `public/illustrations/web-rendering.png`: Cream browser sends Request to a charcoal server; Response includes HTML/CSS/JS; Render browser shows mountain content, linked by teal cable. Wide 2.4:1.
- `public/illustrations/notebook.png`: Open cream developer notebook with web apps, APIs, cloud, and Ideas → Build → Learn; black pen and teal cable.
- `public/illustrations/envelope.png`: Closed cream envelope with fine dark contours, teal cable, and orange emphasis strokes.
- `public/illustrations/contact-letter.png`: Open cream envelope containing a letter with N/B keycaps, connected to a code browser by teal cable.
- `public/illustrations/projects.png`: Cream project folders, front titled Projects; browser thumbnail, yellow pencil, teal cable.
- `public/illustrations/image-generator.png`: Two overlapping sunset mountain-lake prints with a cream prompt card reading A serene mountain lake at sunset, and Generate with DALL-E note.
- `public/illustrations/student.png`: Student Management attendance notebook with teal checks, calendar, yellow pencil, and plant.
- `public/illustrations/bootcamp.png`: Web Development Bootcamp spiral notebook with React example and a browser map with orange location pin.
- `public/illustrations/merchant.png`: Cream storefront with orange striped awning, teal smartphone showing a checkmark, receipt, and plant.
- `public/illustrations/blog-notebooks.png`: Stacked cream and teal notebooks, code symbol, orange bookmark, and looping cable.
- `public/illustrations/first-post.png`: Cream spiral notebook headed # My First Post; ink lines, mountain thumbnail, teal cable, orange strokes.
- `public/illustrations/second-post.png`: Loose cream papers headed # My Second Post; checklist, yellow pencil, orange strokes.
- `public/illustrations/build-learn.png`: Small signpost with cream BUILD arrow, orange LEARN arrow, and dark teal post.
- `public/illustrations/paper-plane.png`: Cream paper airplane pointing upper-right, fine ink folds, teal cable, and orange emphasis strokes.

The Lyriks and Greattr website screenshots reuse the original repository assets. Project illustration alt text explicitly identifies them as illustrations.
