[Underdog Woof](https://huggingface.co/ConwayResearch/Underdog-Woof) is a small English **text-to-speech (TTS) model**. You give it written text, and it generates spoken audio on your own computer.

The downloadable release fits two voices into a model file of about 40.6 MB and runs on a CPU with Python and NumPy. It doesn’t need a GPU or an API key. Once the files and dependencies are downloaded, speech generation runs locally.

I tried it on my Mac. Here’s what it can do, how the local setup works, and the recordings I saved while testing it.

| Model detail | Downloadable release tested here |
| --- | --- |
| Task and language | English text-to-speech |
| Model file | About 40.6 MB for the two-voice version |
| Runtime | Local CPU inference with Python and NumPy; no GPU or API key required |
| Voices and output | Juno and Mira; 24 kHz mono WAV |
| Offline use | Speech generation works offline after downloading the files and dependencies |
| License | Non-commercial with attribution; commercial use requires a separate license |

These release details come from the [official model card](https://huggingface.co/ConwayResearch/Underdog-Woof). The recordings and timing observations below come from my own local tests.

## What can Underdog Woof do?

Woof’s released runtime handles a few practical parts of turning a script into speech:

- **Generate English speech locally.** Pass in your text and save the output as a WAV file.
- **Read numbers and everyday notation.** A built-in normalizer rewrites dates, times, phone numbers, prices, codes, and symbols into spoken forms.
- **Handle longer text.** The runtime splits text into sentences and clauses, then joins the generated pieces.
- **Choose between two built-in voices.** The downloadable model includes Juno and Mira.
- **Try another take.** Change the seed to generate a variation, or keep the seed fixed for repeatable generation with the same text and setup.

These features are described in the [official runtime documentation](https://huggingface.co/ConwayResearch/Underdog-Woof#usage). The released interface doesn’t include a reference-audio input for cloning your own voice, and the model is documented for English.

A small download makes it easy to experiment. Pronunciation and delivery still need a listening check on the text you actually want to use.

## What is actually running locally?

The [model repository](https://huggingface.co/ConwayResearch/Underdog-Woof) contains the weights and a NumPy inference runtime. NumPy is the only dependency listed in its requirements file. The runtime writes mono audio at 24 kHz and saves it as a WAV file.

There are two sizes mentioned in the release. The **31.7 MB version** has one voice and is used in the browser demo. The **40.6 MB version** in the downloadable repository has Juno and Mira. This post covers the two-voice download.

The model-file size is also different from its memory use while running. The publisher reports hundreds of megabytes of peak memory for the NumPy version. I didn’t measure memory usage in my own test.

## How I tried it on my Mac

I used a separate folder and a Python virtual environment. Here’s a setup you can use from scratch; use an empty folder name if `underdog-woof` already exists:

```bash
mkdir underdog-woof
cd underdog-woof
python3 -m venv .venv
source .venv/bin/activate
python -m pip install numpy huggingface_hub
hf download ConwayResearch/Underdog-Woof --local-dir .
```

The Hugging Face package supplies the `hf` download command. Woof itself uses NumPy for inference. You need an internet connection for the download and package installation; the downloaded runtime generates audio locally.

Start with a short sentence:

```bash
python -m underdog_woof 'Hello! This is my first local speech test.' --voice juno -o juno.wav
afplay juno.wav
```

Then give Mira exactly the same text:

```bash
python -m underdog_woof 'Hello! This is my first local speech test.' --voice mira -o mira.wav
afplay mira.wav
```

`afplay` is the playback command on macOS. On another operating system, open the WAV file in an audio player.

The output filename is yours to choose. Reusing a filename replaces the earlier output, so use different names for takes you want to keep. When you open a new terminal, return to the folder and activate `.venv` again.

For another take, change the seed:

```bash
python -m underdog_woof 'Hello! This is my first local speech test.' --voice juno --seed 1 -o juno-take-2.wav
```

Run `python -m underdog_woof --help` to see the supported options. I would leave the temperature at its default while getting a feel for the voices.

## How fast was the first test?

During setup, we ran a separate short greeting in each voice. The CLI reported:

| Voice | Generated audio | Generation time | Audio seconds per second of generation |
| --- | ---: | ---: | ---: |
| Juno | 8.88 seconds | 1.53 seconds | 5.8 |
| Mira | 15.96 seconds | 4.48 seconds | 3.6 |

These are one run per voice on my Mac. The [CLI timer](https://huggingface.co/ConwayResearch/Underdog-Woof/blob/be702960539777fc3f698e54335276a8391b00f9/underdog_woof/__main__.py) measures generation after the model is loaded and before the WAV is saved. It excludes downloading, installation, model loading, and file writing.

The longer clips embedded above came from my later test. Their durations don’t supply generation timings, and this small experiment doesn’t establish how Woof compares with other speech models.

For my first local TTS experiment, the small download and short commands made Woof easy to try. Both voices generated the passage on my Mac, and the two initial greetings generated faster than their playback durations. I’d still test pronunciation on the script I actually need and check the license before using it in a project.

## A few things to try next

The official runtime includes text normalization for numbers, dates, prices, and codes, plus splitting for long text. A useful next test is a sentence you might actually need spoken, with the names and numbers you care about. Check the result by listening all the way through.

For example, the [publisher’s sample](https://huggingface.co/ConwayResearch/Underdog-Woof#samples) includes a phone number and a time:

```bash
python -m underdog_woof 'Please call me back at 415-555-0199 before 5:30 p.m. on Friday.' --voice juno -o numbers.wav
```

The released model is documented for **English**. It has two built-in voices, and the released interface doesn’t include a reference-audio input for cloning your own voice. Listen for pronunciation and pacing on your own text before deciding whether it fits your use.

## Check the license before publishing

The downloadable model uses the [Underdog Non-Commercial License 1.0](https://huggingface.co/ConwayResearch/Underdog-Woof/blob/main/LICENSE). It permits non-commercial use with attribution. Published audio needs “Underdog Woof” or “underdog.ai” in the title or description; an app using it needs a visible voice credit.

Local commercial use, including monetized or sponsored videos and company work, requires a separate written license. The publisher lists `license@conway.tech` for that. The license also has separate terms for use through Underdog’s own products, so check the terms for the way you intend to use it.
